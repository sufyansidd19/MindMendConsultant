# 🧠 Mind Mend Consultant

Mind Mend Consultant is a web-based platform designed to connect patients with certified psychological therapists for online therapy sessions. It offers secure appointment booking, session feedback from both patients and therapists and intelligent therapy recommendations.

## ✨ Features

### 👤 Patient Features
- Register & login with secure authentication.
- Book appointments for online sessions with available therapists.
- Submit feedback on therapist performance after each session.
- View personal health profile & progress.
- Get AI-based suggestions on how many more therapy sessions are recommended.

### 🧑‍⚕️ Therapist Features
- Register & login with secure authorization.
- View and manage booked appointments.
- Submit feedback on patients' mental health condition after each session.

### 🔒 Security
- **Authentication & Authorization** for separate patient & therapist portals.
- Protected routes to prevent unauthorized access.

### 📊 Health Tracking
- Aggregates patient feedback & therapist reports.
- Generates therapy session recommendations based on ongoing health condition.
